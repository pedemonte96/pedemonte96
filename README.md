## Selected work

### [`causaleffect`](https://github.com/pedemonte96/causaleffect)

Open-source Python library for identifying conditional and non-conditional causal effects in graphical causal models, implementing algorithms from the causal inference literature.

[PyPI](https://pypi.org/project/causaleffect/) · [Documentation](https://pedemonte96.github.io/causaleffect/) · [Paper](https://doi.org/10.48550/arXiv.2107.04632)

### [`Hrare2023`](https://github.com/pedemonte96/Hrare2023)

Scientific computing and statistical analysis for searches for rare Higgs-boson decay channels using data from the CMS experiment at CERN, developed during my Master's research at MIT.
